╔══════════════════════════════════════════════════════════╗
║         SPREADHUNTER — RODAR VIA PYTHON (DEV)            ║
╚══════════════════════════════════════════════════════════╝

Modo recomendado para diagnóstico. Mostra mensagens de erro
reais no console em vez de só "parou de funcionar" do .exe.

───────────────────────────────────────────────────────────
1. PRÉ-REQUISITOS
───────────────────────────────────────────────────────────

- Python 3.13.14  (>= 3.12 também funciona)
  Download: https://www.python.org/downloads/release/python-31314/
  IMPORTANTE: marque "Add Python to PATH" na instalação

- Windows 10/11 com Open Fast Trader rodando (ou Profit com RTD)

───────────────────────────────────────────────────────────
2. PRIMEIRA INSTALAÇÃO (uma vez só)
───────────────────────────────────────────────────────────

Abra o PowerShell na pasta do projeto e rode:

    python -m pip install -r requirements.txt

Se der警告 de permissão, abra o PowerShell como Administrador.

───────────────────────────────────────────────────────────
3. CONFIGURAR .ENV
───────────────────────────────────────────────────────────

Renomeie .env.example para .env e edite:

    OPCOESNET_CPF=SEU_CPF_AQUI
    OPCOESNET_SENHA=SUA_SENHA_AQUI

───────────────────────────────────────────────────────────
4. RODAR
───────────────────────────────────────────────────────────

    python main.py

A aplicação vai abrir em uma janela. Se der erro, ele aparece
no TERMINAL (não só na tela). Copie e mande pro suporte.

───────────────────────────────────────────────────────────
5. PROBLEMAS COMUNS
───────────────────────────────────────────────────────────

- "ModuleNotFoundError: PySide6"
  → pip install -r requirements.txt não rodou. Tente de novo.

- "OpenFastSocketAdapter não conecta"
  → Abra o FastTrader antes. Verifique localhost:557 ou a porta
    configurada em Parâmetros > Geral > Fonte Market Data.

- "Profit não aparece"
  → Profit deve estar aberto COM o servidor RTD ativo.

- "sqlite3.OperationalError: no such table"
  → Rode: python -c "from src.infrastructure.persistence.database import init_db; init_db()"

───────────────────────────────────────────────────────────
6. RODAR OS TESTES (opcional)
───────────────────────────────────────────────────────────

    python -m pytest tests/ -x -q --tb=short

Deve mostrar 383 passed em ~60-90s.

───────────────────────────────────────────────────────────
7. DEPLOY PARA PRODUÇÃO (gerar .exe)
───────────────────────────────────────────────────────────

Só quando tudo estiver OK em dev:

    python -m PyInstaller --clean --distpath "$env:USERPROFILE\Desktop\dist" --workpath "$env:USERPROFILE\Desktop\build_pyi" spreadhunter.spec

Copia o .env pra dentro do dist\Spreadhunter antes de mover
para o Desktop.

───────────────────────────────────────────────────────────
DÚVIDAS? Mande o stacktrace completo do Python (a parte
em vermelho que aparece quando dá erro).
